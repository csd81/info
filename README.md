# Applied Information Theory — Course Notes

Course notes for a single-semester university course on applied information theory,
split into six chapter PDFs.

**Authors:** István Vassányi, Benedek Szakonyi
**Institution:** University of Pannonia (Pannon Egyetem), Veszprém, Hungary
**Year:** 2019

> This text attempts to present an application-oriented introduction to information
> theory, with fewer theorems and proofs than usual, and more engineering
> considerations. The approach and notation are very similar to those of the excellent
> textbook [1], with some simplifications and extensions that seemed necessary for a
> single-semester university course.
